01 мессенджер

Anongram

Анонимный мессенджер со сквозным шифрованием: ключи генерируются на устройстве, сообщения шифруются X25519 + AES-GCM и не читаются сервером. Поиск собеседника по отпечатку ключа.

  • Flutter
  • Dart
  • X25519
  • AES-GCM
  • Ed25519
02 игра

Snake: Python + Flutter

Змейка в двух версиях: десктопная на Python/Tkinter и мобильная на Flutter. Три сложности с плавным ускорением, свайп-управление, отрисовка через CustomPainter. Сборка релизного APK.

  • Python
  • Tkinter
  • Flutter
  • Kotlin
03 безопасность

Локальное хранилище секретов

Слой Vault для приватных данных: ключи не покидают устройство, обмен сессионными ключами через HKDF, восстановление аккаунта по seed-фразе.

  • Dart
  • HKDF
  • Crypto
  • SharedPreferences
